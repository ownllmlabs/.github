# Security policy

## Reporting a vulnerability

If you find a security problem in anything we publish, please tell us privately first. Do not open a public issue.

- Email: [security-email@your-domain.com]
- Include: what you found, which repository and file, steps to reproduce, and the possible impact.

We will acknowledge your report as soon as we reasonably can and keep you informed. We are a very small team, so we cannot promise a fixed response time.

## Scope

This policy covers the open material published under the OwnLLM Labs organization. Our reference configurations are examples and starting points. They are not hardened production systems, and they do not come with security guarantees.

## Please do not

- access, change or delete data that is not yours
- disrupt any service
- publish details of a problem before we have had a reasonable chance to fix it

## Safe handling of data

Our repositories must never contain real client data, patient data, credentials or private server addresses. If you find any, report it using the email above, and we will remove it.
