# Contributing

Thank you for helping improve OwnLLM Labs' open material. We are a small team, so please be patient with replies.

## Ways to help

- Report an error, unclear instruction or outdated statement by opening an issue
- Suggest an improvement to a guide or checklist
- Share the results of testing one of our reference setups on your hardware

## Before you open an issue or pull request

1. Check whether it has already been reported.
2. Say which repository and file you are referring to.
3. For setup problems, include your operating system, hardware, software versions and the exact error.
4. **Never include real client data, patient data, passwords, keys or private server addresses.** Use synthetic examples.

## Pull requests

- Keep each pull request focused on one change.
- Explain what changed and why.
- Do not add claims about security, compliance, performance or cost unless you can show how they were measured. State the hardware, software versions and date for any benchmark.
- By contributing, you agree that your contribution can be published under the repository's license.

## Reviews

We review contributions when we can. We may decline changes that do not fit the scope of a repository.
